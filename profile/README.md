<h1 align="center">Attestory</h1>

<p align="center"><strong>Full chain of custody for machine-built software.</strong></p>

<p align="center">
Other tools govern what agents <em>do</em>; Attestory governs what gets
<em>delivered</em> — priced, provenanced, and gated at the merge.
</p>

> **No unit of work reaches main without provenance, price, and approval.**

First product: **remit** — governed delivery for AI-assisted engineering. One
static Go binary: gate as a PreToolUse hook, cost meter, risk-tiered merge
(R0–R4), append-only ledger. Apache-2.0 open core. It develops itself under
its own governance — every change to the tool passes through the tool.

**Status:** private beta — repositories flip public at v0.1.
